# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-18

### Added
- Top-down multi-agent algorithmic crypto trading framework powered by LangGraph.
- Specialized agents for Macro Trend, Chart Pattern, News Sentiment, and Risk Management.
- Modular architectural structure with unified `src/` facade and clean separation.
- Single-command Makefile workflow for installation, testing, linting, and running.
- Multi-aspect CI validation including Ruff linting, test suite, and Trivy security scanning.
- Pre-commit hooks for automated code formatting and static code quality.
- Formal open source governance and vulnerability disclosure policies.
