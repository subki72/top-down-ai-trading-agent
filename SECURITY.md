# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it via private disclosure rather than opening a public issue.

Email security notifications to: `subki.dev@gmail.com` with:
- Summary of the vulnerability
- Reproduction steps or proof of concept
- Expected impact

All vulnerability reports receive a response within 48 hours with triage status and patch timeline.
